# Personal Finance Manager

A Python application for tracking income and expenses and seeing where your money goes.

*Built for the Python course in my master's program, 2025.*

## Features

- Add, edit and delete transactions
- Categorize income and expenses
- View balance and spending summaries by category and month
- [Charts / CSV export / budgets — edit to match yours]

## Tech

- Python
- [e.g. pandas, matplotlib, Tkinter, SQLite / JSON storage]

## Getting started

```bash
git clone https://github.com/USERNAME/personal-finance-manager.git
cd personal-finance-manager
pip install -r requirements.txt
python main.py
```
